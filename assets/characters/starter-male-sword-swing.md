# v1.4.7 — right-hand running sword swing
Adds a small outward blade lift of 10–20 degrees to the existing grip-relative angle for each of the four running frames in eight directions, capped at 82 degrees from downward to avoid lifting the blade tip toward the head. Rotation pivot is exactly the existing hand socket. The left-hand overlay, standing poses, far/near layering, art, equipment stats, damage, and movement are unchanged. No extra textures. The game currently has a single moving animation; this applies whenever that animation is active, not separate walk/run speed tiers. Mock Canvas comparison against v1.4.6 verifies all 32 running poses and 8 idle poses, grip positions, left-hand/unarmed/dual equipment, paused and fallback behavior, and balanced Canvas state. Live iPad visual tuning remains necessary.
