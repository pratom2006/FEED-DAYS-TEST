# v1.6.0 — Dynamic normal attack timing
AGI 5 preserves the 380ms default. Rate = clamp(1 + 0.5*max(AGI-5,0)/(100+max(AGI-5,0)) + optional equipment/character aspdBonusPct/100, 0.5, 1.5). All normal attacks share cadence; optional modifiers supported but no new items/buffs granted. No weapon-type base differences yet. Duration rounded per accepted attack; damage and crit calculated at acceptance and applied once at ceil(duration*165/380), start of frame 3, if same player/map/equipment, target alive and in range, and game active. Miss/cancel consumes cooldown except map/session resets. Pending attacks canceled on menu/pause/hidden, invalid target or overdue clock. Existing skill branch, damage formula, items, saves, normal and dual run sprites unchanged. East sword animation and slash use normalized time; legacy basic hit VFX duration scales with cycle. Other directions/equipment still lack custom attack sprite but use shared hit timing. Status UI shows ASPD and attacks/sec. Deterministic tests cover five speed cases, nine cancel cases, 12 attack pose samples and 64 movement regression checks. No live device or Pages deployment verification.
