# v1.4.9 — upward diagonal running sword
Right-hand moving blade now stays between 125 and 150 degrees measured from downward, so the tip points diagonally upward for every running pose. A fixed screen side per direction prevents abrupt 180-degree swings when the fist crosses the sprite center. Hand pivot, idle, left hand, layering, movement, stats and combat are unchanged. Angles are initial artistic tuning; upward blade may overlap hair/body in some poses, requiring device visual checks. Mock Canvas comparison verifies 32 running and eight idle poses, upward tip, consistent side, grip, layering, single/dual/unarmed, pause, fallback and syntax.
