# v1.5.1 — Combat Front east trial
Owner-approved weapon-free four-frame east-facing artwork is cropped, alpha cleaned and normalized to four 96×96 cells, baseline 92, in a 384×96 lossless WebP. Original normal movement images remain unchanged. When a male unmounted character moves east with two distinct one-handed sword/dagger items, the new pose is used if its image is ready; otherwise the existing animation is used. Both weapons point forward; right nominal 135°, left nominal 140°, with ±2° per-frame motion. Separate grip sockets are registered for all four cells; left blade behind and right blade in front as previously. Existing game item names identify swords/daggers including Thai names, excluding known two-handed names/flags. No changes to equipment or combat rules, saved data, idle, other directions, or weapon art. Mock Canvas tests cover the new four frames, both blade slots, asset-not-ready fallback, other directions, non-blades, single/unarmed, idle/pause/menu and legacy rendering. Actual device/deployment visual testing remains necessary. Greatsword/scythe animations are not included.
