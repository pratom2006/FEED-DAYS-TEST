# v1.5.0 — dual sword animation
Both independent equipped hand overlays now point diagonally upward (125–150° from downward) while moving. The right-hand motion remains identical to v1.4.9. Left-hand angle profile is offset by two of the four frames, with opposite fixed screen-side orientation, so tips counter-swing without flipping side within a direction. Each weapon retains its own existing fist socket, and existing near/far layering and idle poses are unchanged. Works with right-only, left-only, both, or no equipment. Uses existing generic sword art for equipped slots; no new weapon types, combat, equip rules, stats, or saved-data changes. Future two-handed greatswords/scythes need separate pose and grip profiles, one shared weapon transform using both hands, slot occupancy rules and weapon-specific art; not implemented here. Mock Canvas tests compare all 32 running and eight idle poses, angle, phase, sockets, layers, pause/menu and fallback against v1.4.9. Live device visual overlap checks remain necessary.
